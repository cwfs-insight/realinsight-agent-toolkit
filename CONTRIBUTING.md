# Contributing

This repository is currently maintained by Realinsight.

Most runtime code is generated by the Realinsight release pipeline. Before editing generated files directly, check [docs/release-process.md](docs/release-process.md) to confirm whether the file is repo-owned or export-owned.

Good direct-edit targets:

- Root README and install docs.
- Host-specific install instructions.
- Catalog and marketplace metadata.
- Security, release, and packaging guidance.

Avoid direct edits to generated runtime and copied skill bundles unless you are also updating the exporter that produces them.
