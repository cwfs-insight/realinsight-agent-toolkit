# Realinsight Connector Claude Provider

This folder is a Claude Code marketplace root for the prod Realinsight connector.

Plugin: `realinsight-connector`
MCP endpoint: `https://www.realinsight.cloud/api/v1/mcp`

When adding from GitHub, use this folder path:

```text
providers/claude/prod
```

Install `realinsight-connector` from the `realinsight` marketplace.
