# Realinsight Connector QA Codex Provider

This folder is a Codex marketplace root for the qa Realinsight connector.

Plugin: `realinsight-connector-qa`
MCP endpoint: `https://www.ri2-qa.com/api/v1/mcp`

When adding from GitHub, use this folder path:

```text
providers/codex/qa
```

Install `realinsight-connector-qa` from the `realinsight-qa` marketplace.
