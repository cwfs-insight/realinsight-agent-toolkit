# Realinsight Connector Dev Codex Provider

This folder is a Codex marketplace root for the dev Realinsight connector.

Plugin: `realinsight-connector-dev`
MCP endpoint: `https://www.ri2-dev.com/api/v1/mcp`

When adding from GitHub, use this folder path:

```text
providers/codex/dev
```

Install `realinsight-connector-dev` from the `realinsight-dev` marketplace.
